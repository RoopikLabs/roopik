# Build Commands

| Command | Description |
|---------|-------------|
| `npm run build` | Build webview + extension |
| `npm run build:webview` | Build webview only |
| `npm run build:extension` | Build extension only |
| `npm run watch` | Watch extension only |
| `npm run watch:all` | Watch both (needs concurrently package) |
| `npm run postinstall` | Auto-installs webview deps when you npm install |

> **Note:** Build Core separately via main project.
